## 你的創作流程

**組織素材 → 導演鏡頭 → 比較候選 → 剪輯匯出**

連接圖片、音訊、影片和可編輯 3D 節點，逐個鏡頭建立你的世界，再用時間軸完成配樂、字幕與剪輯。
