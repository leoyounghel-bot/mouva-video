# 本地开发说明

[返回项目首页](../README.md) · [操作指南](usage.md) · [部署文档](deployment.md)

## 安装与启动

需要 Node.js 24.11 或更新版本。渲染需要 Chromium 和 FFmpeg。

```sh
npm ci
cp .env.ai.example .env.ai
npm run dev
```

打开 <http://127.0.0.1:5173>。编辑画布、调整场景和渲染运动参考不需要生成服务密钥；使用 AI 生成时需要在后端配置对应服务。

## 私有环境配置

按 `.env.ai.example` 在本地填写 `.env.ai`，仅保存在后端或私有密钥存储中。

| 配置项 | 用途 |
| --- | --- |
| `CHROME_PATH` | Chrome 或 Chromium 可执行文件路径。 |
| `FFMPEG_PATH` | FFmpeg 可执行文件路径；已加入系统 PATH 时可以省略。 |
| `GEMINI_API_KEY` | 场景规划与编辑服务的后端凭据。 |
| `ARK_API_KEY` | 视频生成服务的后端凭据。 |
| `DEEPINFRA_API_KEY` | 图片生成服务的后端凭据。 |
| `MOUVA_ACCESS_TOKEN` | 本地模式服务对外开放时使用的工作区访问令牌，在服务器连接入口填写。 |

视频生成还需要可公开访问的 HTTPS 媒体地址。生成服务与模型参数以环境配置示例和后端实现为准；访问令牌与生成服务凭据用途不同。

不要把服务密钥放入 `VITE_*` 配置，这类变量会随前端构建发送给浏览器。公开配置文件中的部署地址仅为占位值。

## 测试、构建与运行

```sh
npm run check:public
npm test
npm run test:harness
npm run build
npm start
```

生产构建通过服务端提供，默认端口为 5175。公开源码检查同时在持续集成中运行，检查凭据和私有文件；详见[安全说明](../SECURITY.md)。

## 服务结构

前端由 Cloudflare Workers 提供静态资源。独立 Node 服务运行任务队列、Chromium、FFmpeg 和可选生成服务。浏览器通过同源 `/api/ai/*` 代理调用后端，服务密钥保留在后端。

如需部署，按[部署文档](deployment.md)配置。托管登录流程使用 `VITE_MOUVA_AUTH_MODE=mouva` 和匹配的服务端参数。独立安装可以保留本地模式，或对接自己的账号服务；本仓库不包含 Mouva 主账号服务及其数据库。

## 账号与存储

- 托管模式通过服务端固定的身份接口核验账号。一次性交接凭据有效期为 60 秒，并绑定发起请求的浏览器；主账号访问令牌不会放入重定向地址，也不会由视频服务持久保存。
- 视频会话使用独立签名的安全 Cookie，有效期为八小时。任务、上传、幂等键和父任务引用均核验所属账号。
- 浏览器中的项目、素材与界面状态按账号区分，目前保存在该浏览器内，尚未实现跨设备项目同步。
- 完整媒体地址可用于播放和渲染，知道地址的人可以获取文件，但不能因此获得任务管理权限。
- 磁盘任务队列面向具有持久卷的单个后端实例，两种导出流程共用一个渲染槽位。多实例部署需要共享存储和分布式队列。

托管服务可以通过私有认证的计费接口共享积分账本；启用前需要匹配的账号服务迁移和已确认的费率。具体见[计费说明](billing.md)。

## 合成测试媒体

`npm run preview:reference` 可启动仅监听本机的测试网关，默认端口为 5176。它只提供明确选定的测试项目中带签名的 `reference.mp4`，拒绝管理接口、上传、其他媒体和其他项目。

使用 `MOUVA_PREVIEW_DATA_DIR`、`MOUVA_PREVIEW_PROJECT_ID` 和 `MOUVA_PREVIEW_PORT` 指向隔离的验收后端。临时 HTTPS 隧道可用于经授权的合成视频测试，测试完成后应关闭。该网关不能替代生产媒体服务，也不会让其他项目自动具备视频生成条件。
