# Mouva Video 操作指南

[返回项目首页](../README.md)

## 新建与切换项目

点击顶部项目名称旁的「新建项目」，输入名称并选择横屏、竖屏或方形画幅。新项目从一个空白视频节点开始。

切换前会保存当前项目；通过项目菜单可以返回已保存项目。项目和导入素材保存在当前浏览器中，按登录账号区分，暂不支持跨设备同步。

## 搭建画布

通过底部「＋」添加节点，或双击空白画布打开节点菜单。

| 节点 | 用途 |
| --- | --- |
| 图片 | 上传参考图，或输入描述生成图片，采用后保留原有连接。 |
| 视频 | 制作与比较镜头候选，选择采用的版本，再加入时间线。 |
| 音频 | 导入、试听和编辑人声、音乐或音效。 |
| 3D | 编辑场景对象、相机与动作，制作可编辑的运动参考。 |

从节点右侧输出端口拖到另一节点左侧输入端口，即可建立连接。连接会随项目保存，刷新页面和切换项目后仍会保留。新建项目或节点不会自动发起生成。

## 移动与缩放

在缩放百分比菜单中选择鼠标类型；系统会记住偏好。

| 操作 | 方法 |
| --- | --- |
| 苹果鼠标或触控板平移 | 滑动以平移；按住 Control 并上下拖动或滑动，以指针为中心缩放。 |
| 标准鼠标缩放 | 滚动滚轮缩放；按住 Shift 滚动可横向平移。 |
| 移动节点 | 在选择模式下拖动卡片的画面或标题。 |
| 移动画布 | 拖动空白区域、按住空格拖动，或切换到平移模式。 |
| 调整缩放 | 使用「− / ＋」、缩放预设，或 Ctrl / ⌘ 加减号。 |

快捷键 V 切换选择模式，H 切换平移模式。预览按钮和进度条可以直接操作。

## 制作图片与镜头

图片生成入口位于工作区顶部、素材库和创作助手中。输入描述，可附上最多四张 PNG、JPEG 或 WebP 参考图；每轮可选择 1、2 或 4 个候选。

完成的候选保留在当前项目的历史记录中。选择采用后，图片会保存为项目素材，可以用于镜头参考或连接到画布节点。关闭面板不会停止已排队的任务；要停止后续候选，请使用「停止生成」。

图片和 3D 节点连接到视频节点后，可分别提供外观参考与渲染后的运动参考。默认保留已有 3D 场景；需要重新设计时再勾选修改场景。已连接的 3D 优先使用最新编辑设置，源场景和历史候选仍可比较、采用或继续生成。

## 使用创作助手

创作助手提供速度、裁剪、字幕和色彩调整，也支持通过自然语言描述修改。这些操作影响已采用的版本，可以撤销；编辑前请先切回需要修改的已采用版本。

最近的对话与未发送输入按账号和项目保存在本地。刷新后可恢复对话上下文，但待执行的编辑方案需要结合当前项目重新规划。

## 编辑时间线

时间线预览和导出都使用已采用版本。拖动标尺或播放头定位，单击片段选择相应剪辑工具。

| 素材 | 可用操作 |
| --- | --- |
| 视频 | 拖动调整顺序，拖动边缘裁剪时长。 |
| 音频 | 移动、跨轨道调整、裁剪、分割、复制和调整音量；重叠音频自动分行。 |
| 人声、音乐和音效 | 在音频节点中选择对应加入按钮，在当前播放位置插入；也可以直接导入或拖入轨道。 |

双击音频打开详细设置，轨道名称旁的「＋」可继续导入。混音、字幕和视频通过时间线预览与导出；音频不作为视觉生成参考。

| 快捷键 | 操作 |
| --- | --- |
| S | 在播放头处分割选中的视频或音频。 |
| Delete | 删除选中片段。 |
| Ctrl / ⌘ + Z | 撤销。 |
| Shift + Ctrl / ⌘ + Z | 重做。 |
| Escape | 取消当前拖动。 |

## 学习与案例

打开侧栏的书本图标、素材库的学习入口，或进入 `/?section=learn`。课程覆盖画布、图片、助手编辑、候选、3D、导出与武侠案例；学习进度会保存。

「雨门交锋」会打开包含八个镜头的练习副本，内置视频与动画 GLB。原项目先保存，再进入练习；返回时也会保存练习进度。播放、标题和 0.75 倍速练习使用已有素材，不会自动提交新生成任务。导出仍通过正常渲染流程处理。

武侠 AI 视频与 3D 动作分别制作。太空旅行的 3D 预演也独立于成片，详见[首页案例说明](../README.md)。

## 线上积分

启用线上计费后，生成前会显示服务端报价。每个候选单独预留积分，采用版本不收费。完成任务结算一次；确认失败时释放未使用的预留，状态不明确的请求等待核对。

通过积分与账单页面查看余额和记录。详细配置见[计费说明](billing.md)。
