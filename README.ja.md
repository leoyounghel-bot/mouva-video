## 創作の流れ

**素材を集める → ショットを演出する → テイクを比較する → 編集して書き出す**

画像、音声、映像、編集可能な 3D ノードをつなぎ、ショットごとに世界を構築。音楽や字幕を加え、タイムラインで物語を仕上げます。
